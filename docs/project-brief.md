# Project brief (edit if needed)

Deadline Tracker helps university students who juggle several courses keep every assignment and due date in one place. Typing deadlines from each syllabus by hand is tedious and error-prone, so the app lets you paste a syllabus and uses an LLM to extract assignments and dates as validated structured data that you review before saving. I chose it because I use it myself and it was already my project from Week 1.
